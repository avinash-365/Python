# 📖 Project Overview

**Employee Management System** is a menu-driven Python application developed using **Object-Oriented Programming (OOP)** principles.

The system allows users to create and manage different types of employees while demonstrating important OOP concepts such as inheritance, encapsulation, constructors, method overriding, getters & setters, and class variables.

---

# ✨ Current Features

✅ Create Employee

✅ Create Manager

✅ Create Developer

✅ View Employee Details

✅ View Manager Details

✅ View Developer Details

✅ Automatic Employee ID Generation

✅ Salary Validation using Setter Method

✅ Encapsulation using Private Variables

✅ Menu-Driven Interface
