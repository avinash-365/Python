# 📖 Project Overview

**Data Analyzer and Transformer** is an interactive Python program that allows users to input a dataset and perform different operations using Python functions.

The project demonstrates important Python concepts including recursion, lambda functions, sorting, built-in functions, multiple return values, and menu-driven programming.

---

# ✨ Features

✅ Input Numerical Dataset

✅ Display Data Summary

✅ Calculate Factorial (Recursion)

✅ Filter Data using Lambda Function

✅ Sort Data (Ascending & Descending)

✅ Display Dataset Statistics

✅ Return Multiple Values

✅ Menu-Driven Interface
