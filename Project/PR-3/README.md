## 📖 Overview

Student Data Organizer is a menu-driven Python application that helps users manage student records efficiently.

The application allows users to:

* ➕ Add Student Records
* 📋 Display All Students
* ✏️ Update Student Information
* ❌ Delete Student Records
* 📚 View Unique Subjects Offered
* 🚪 Exit the Program

Each student receives a unique ID automatically.

---

## ✨ Key Features

| Feature               | Description               |
| --------------------- | ------------------------- |
| ➕ Add Student         | Store student information |
| 📋 Display Students   | View all saved records    |
| ✏️ Update Student     | Modify existing details   |
| ❌ Delete Student      | Remove student records    |
| 📚 Subject Management | Display unique subjects   |
| 🆔 Auto ID Generation | Automatic student IDs     |
